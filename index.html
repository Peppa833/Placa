Uso de KiCad para la fabricacion de la PCB

Documentación de el uso de KiCad.

Descargar el programa

Como primer paso se descarga el programa de KiCad para la fabricacion y diseño de circuitos, despues se añade la libreria FabLab que contiene lo necesario para las practicas.

Editor de Esquemas

Se utiliza el editor de esquemas de KiCad donde se empieza el diseño de el circuito en base a lo que explico el profesor con anterioridad, para la fabricacion del circuito se utilizan los componentes de la libreria de FabLab.

El circuito cuenta con una fuente de alimentacion de 3.3V y una tierra o (GND), se añadieron 8n resistencias y 4 LED's con 4 botones para que cada boton pudiera controlar un LED, gracias a cada resistencia se regula el paso de corriente y se evitan corocircuitos , gracias a esta practica se comprende mejor el uso de KiCad y de los componentes.
