# Proyecto Placa

Página web simple hecha en HTML que muestra un título centrado con una tipografía personalizada.

## Descripción

Este proyecto consiste en una página HTML minimalista que despliega el texto **"proyecto placa"** como encabezado principal, centrado en la pantalla y con la fuente **Poppins**.

## Estructura del proyecto

```
├── index.html
└── README.md
```

## Tecnologías utilizadas

- HTML5
- CSS3 (estilos embebidos)
- Google Fonts (Poppins)

## Cómo usarlo

1. Descarga o clona el archivo `index.html`.
2. Ábrelo en tu navegador favorito (doble clic o clic derecho → Abrir con...).
3. ¡Listo! Verás el título centrado en la página.

## Personalización

Puedes modificar fácilmente:
- El texto del título (dentro de la etiqueta `<h1>`)
- El color del texto (`color` en la clase `h1`)
- La fuente (cambiando el enlace de Google Fonts y el `font-family`)
- El tamaño del texto (`font-size`)
